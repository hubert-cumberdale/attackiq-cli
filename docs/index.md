# AttackIQ CLI Documentation

AttackIQ CLI is a Python command-line tool for working with the AttackIQ API through a bundled
OpenAPI schema. It supports spec discovery, validated generic calls, first-class read-only
wrappers, dry-run mutation planning, redacted configuration backups, exports, and a read-only TUI.
