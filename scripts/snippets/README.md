# Shared Snippets

Reusable snippets live in this folder. Copy the snippet into the target module and adapt
names or parameters to the specific task.

## How to Use
- Prefer snippets before creating new helpers from scratch.
- Keep redaction logic intact when handling tokens or credentials.
- Add or update tests when integrating a snippet into runtime code.
