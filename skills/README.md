# Agent Skills

Skills are short, reusable playbooks for common tasks. Use the matching skill file
when assigned a task that aligns with its purpose.

## When to Use Skills
- Before starting a task that matches a listed skill, open that skill and follow its steps.
- If multiple skills apply, start with the most restrictive (security or scope) skill.

## Picking a Skill (Examples)
- Adding a new CLI command: use `skills/cli-command-creation.md`.
- Building an export with paging: use `skills/api-pagination-export.md`.
- Reviewing logs or redaction: use `skills/security-review-redaction.md`.
- Editing docs or guidance: use `skills/documentation-updates.md`.
- Running deterministic architecture/security/test reviews: use
  `skills/deterministic-arch-security-test-review.md`.
